# ADR-0004：按积压量自适应收紧发射间隔（有界延迟控制律）

- **状态**：已采纳并实施
- **日期**：2026-09-16
- **影响模块**：`layout/engine.py`（`LayoutEngine.effective_spawn_interval`）

## 背景

弹幕发射采用固定间隔时，只要单位时间到达量超过排空速率，积压会单调增长。后果有两层：
积压期间弹幕严重滞后于画面；视频结束时残留在队列里的事件被永久丢弃。

## 决策

基础排空速率为 `batch_size / spawn_interval`。当积压超过一个批次、且按基础速率清空
积压所需时间超过 `max_latency` 时，临时缩短间隔，把排空速率提升到
`pending / max_latency`。合起来是：

```
drain = max(base_rate, pending / max_latency)
```

## 依据

控制律的稳态解是 `pending* = arrival_rate × max_latency`：只要到达率高于基础速率，积压
收敛到一个**有界**平衡点，而不是像固定间隔那样无限增长。

固定间隔下的对照数据（2026-09-16 实测，同一素材）：p95 延迟 19.5s、最大 38s。

实际排空速率还有天然上限：间隔门每帧最多触发一次，故不会超过 `batch_size × fps`，
极端突发下自动饱和而不失控。

## 后果

- 突发流量下的最坏等待时长有上界，不再是「越积越多直到被截断」。
- `max_latency = None` 表示禁用自适应，退回固定间隔。
